# Meu Cantor Favorito - Renato Russo

Este projeto é uma página web desenvolvida em homenagem ao cantor e compositor brasileiro Renato Russo, líder da lendária banda Legião Urbana.

## Sobre o Projeto

A aplicação apresenta uma visão geral sobre a vida e a carreira do artista, destacando sua trajetória na música nacional, citações marcantes e algumas de suas composições mais emblemáticas, incluindo letras integrais e links para reprodução.

## Funcionalidades

- **Biografia**: Resumo da trajetória de Renato Russo, desde a juventude até o seu legado na música brasileira.
- **Citação**: Frase marcante em destaque.
- **Seção Interativa de Músicas**: Utilização de componentes retráteis (`<details>`) para exibição das letras completas de canções históricas:
  - Tempo Perdido
  - Eduardo e Mônica
  - Faroeste Caboclo
- **Links para Áudio/Vídeo**: Acesso direto para ouvir as canções na plataforma YouTube.
- **Galeria de Imagens**: Fotografias históricas do artista, da banda e capas ilustrativas das músicas.

## Tecnologias Utilizadas

- **HTML5**: Estruturação semântica de conteúdo.
- **CSS3**: Estilização visual, tipografia e personalização de elementos de interface.
